# Jev の帯を測る

`[jev] commit_confidence` は、この表を埋めたあとにだけ書く。英語の 0.9 を初期値にしない。帯を書く前は、Jev の返答は画面のヒントに留まり、台帳にも判断グラフにも書かない。

## 測るもの

未知の日本語メール件名 20 件。本文は送らない。各件について人が選んだ手と、Jev の Choice が一致したかを、confidence の帯ごとに数える。

帯を下限にしてよいのは、その帯が5件以上で、人の手と Choice が全件一致するときだけである。条件を満たす一番下の帯の下限（0.5、0.7、0.85）を `commit_confidence` にする。0.5 未満は下限にしない。該当する帯が無いあいだは項目を空のままにする。`dayloop jev-eval` はこの表を表示するだけで、設定ファイルには書かない。

帯は `0.5 未満`、`0.5–0.7`、`0.7–0.85`、`0.85 以上`。一致数が十分だった一番下の帯だけを `commit_confidence` にする。足りなければ項目を空のままにし、未知の節は質問のまま残す。

## 手順

1. `mode = "on"`、`route` に使うゲートウェイ、環境変数 `DAYLOOP_JEV_API_KEY` を用意する。キーは設定ファイルに書かない。
2. 件名だけを渡す。日付の前後、件数、メール本文、グラフ全件は渡さない。
3. 人が先に手を選ぶ。そのあと Jev の Choice と confidence を記録する。
4. 帯ごとの一致数を下の表に書く。
5. 一致が安定した帯より下は、採用サマリに出さず質問にする。

| 帯 | 件数 | 一致 |
| --- | --- | --- |
| 0.5 未満 |  |  |
| 0.5–0.7 |  |  |
| 0.7–0.85 |  |  |
| 0.85 以上 |  |  |

## HTTP

`HttpDecider` が送る JSON（`state` と `questions[].choices`）は、このクレートのアダプタである。スライドの例示 JSON や未確認の SDK フィールド名とは別物で、公式の形が分かったときに名前を合わせる。CI は実 API を呼ばない。401、429、529、タイムアウト、空の route は未回答として扱い、既知の枝の適用は続ける。
