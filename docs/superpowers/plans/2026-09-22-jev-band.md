# Jev の帯 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 未知20件の一致を帯ごとに数える。`commit_confidence` が空なら未知の節は台帳へ書かない。値が入っているときだけ、その値以上の Choice を枝と台帳へ書く。

**Architecture:** 純関数が帯と下限を計算する。CLI の既定はローカルの表を出すだけ。`--live` は HTTP を呼ぶが、設定ファイルと台帳とグラフは更新しない。CI は実 API を呼ばない。

**Tech Stack:** Rust。基準は `1db379706a833392a315bd153f43ca34aad55b88` と `docs/jev-eval.md`。

帯が採用できる条件は、その帯に5件以上あり、件名に対する人の手と Jev の Choice が全件一致すること。条件を満たす一番下の帯の下限を返す。該当が無ければ `None`。下限は 0.5、0.7、0.85 のどれか。0.5 未満は下限にしない。

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Band { Below50, From50To70, From70To85, AtLeast85 }

pub struct Row {
    pub subject: String,
    pub human: String,
    pub choice: String,
    pub confidence: f64,
}

pub fn band(confidence: f64) -> Band {
    if confidence < 0.5 { Band::Below50 }
    else if confidence < 0.7 { Band::From50To70 }
    else if confidence < 0.85 { Band::From70To85 }
    else { Band::AtLeast85 }
}

pub fn commit_floor(rows: &[Row]) -> Option<f64> {
    for (target, floor) in [
        (Band::From50To70, 0.5),
        (Band::From70To85, 0.7),
        (Band::AtLeast85, 0.85),
    ] {
        let group: Vec<&Row> = rows.iter().filter(|r| band(r.confidence) == target).collect();
        if group.len() >= 5 && group.iter().all(|r| r.human == r.choice) {
            return Some(floor);
        }
    }
    None
}
```

```rust
#[derive(serde::Deserialize)]
struct SheetRow {
    subject: String,
    human: String,
    #[serde(default)]
    choice: String,
    #[serde(default)]
    confidence: f64,
}

pub fn load_sheet(text: &str) -> anyhow::Result<Vec<Row>> {
    let raw: Vec<SheetRow> = serde_json::from_str(text)?;
    if raw.len() != 20 {
        anyhow::bail!("帯の表は20件です: {}", raw.len());
    }
    Ok(raw
        .into_iter()
        .map(|r| Row {
            subject: r.subject,
            human: r.human,
            choice: r.choice,
            confidence: r.confidence,
        })
        .collect())
}
```

`choice` と `confidence` が無い行は空文字と `0.0` になる。空の `choice` は未計測なので、件数に数えない。

```rust
pub fn report(rows: &[Row]) -> String {
    let mut out = String::new();
    for (target, label) in [
        (Band::Below50, "0.5 未満"),
        (Band::From50To70, "0.5–0.7"),
        (Band::From70To85, "0.7–0.85"),
        (Band::AtLeast85, "0.85 以上"),
    ] {
        let group: Vec<&Row> = rows
            .iter()
            .filter(|r| band(r.confidence) == target && !r.choice.is_empty())
            .collect();
        let matched = group.iter().filter(|r| r.human == r.choice).count();
        out.push_str(&format!("{label}: 件数 {} / 一致 {matched}\n", group.len()));
    }
    match commit_floor(rows) {
        Some(floor) => out.push_str(&format!("下限候補: {floor}\nこの値は設定へ書かない\n")),
        None => out.push_str("下限はまだ書かない\n"),
    }
    out
}
```

```rust
                    row.choice = choice;
                    row.confidence = confidence;

                _ => {
                    row.choice.clear();
                    row.confidence = 0.0;
                }
            }
        }
    }
```

- [ ] **Step 3: Write minimal implementation**

`choice` が `done` または `start` のときだけ `revise_task` に渡す。`not_done`、`carry`、`drop` は理由コードが返答に無いので、この関数では適用せず質問のまま残す。`ask` も残す。

```rust
pub fn apply_if_measured(
    store: &Store,
    date: &str,
    decider: &mut dyn Decider,
    floor: Option<f64>,
) -> Result<usize> {
    let Some(floor) = floor else { return Ok(0) };
    let rows = propose_unknown(store, date, decider, floor)?;
    let mut n = 0;
    for row in rows {
        if row.confidence < floor || !matches!(row.choice.as_str(), "done" | "start") {
            continue;
        }
        store.revise_task(&row.id, &row.choice, None)?;
        n += 1;
    }
    Ok(n)
}
```

`close_ritual` の `print_jev_hints` の直後で、`config::load().jev.commit_confidence` をそのまま渡して `apply_if_measured` を呼ぶ。`None` のときは呼ばないか、呼んでも 0 件で戻る。既定の `DEFAULT_TOML` には `commit_confidence` を書かない。
